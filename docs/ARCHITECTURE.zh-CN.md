# NGWebGal 架构设计

## 概述

NGWebGal 是为 WebGal 打造的下一代游戏引擎，使用 C# 和 .NET 10 构建。它为视觉小说和互动小说游戏提供了模块化、可扩展的架构。

## 核心组件

### 1. 游戏引擎 (`NGWebGal.csproj`)
- **用途**：游戏执行的主运行时引擎
- **核心类**：
  - `GameEngine`：管理游戏状态和生命周期的核心协调器
  - `SceneManager`：处理场景加载、转换和状态
  - `DialogueSystem`：处理对话渲染和角色交互
  - `ResourceManager`：管理资源加载和缓存

### 2. 脚本系统
- **语言**：WebGal Script（自定义 DSL）
- **解析器**：对游戏脚本进行词法分析和语法解析
- **执行器**：解释并执行已解析的命令
- **变量**：支持类型转换的动态变量系统

### 3. 资源管理
- **资源类型**：图像、音频、字体、脚本
- **缓存**：使用 LRU 淘汰策略的内存缓存
- **加载**：带进度跟踪的异步资源加载

### 4. 状态管理
- **游戏状态**：跨场景的持久化状态
- **存档/读档**：游戏进度的序列化
- **变量**：全局和局部变量作用域

## 设计模式

- **单例模式**：GameEngine、ResourceManager
- **观察者模式**：游戏状态变化的事件系统
- **工厂模式**：资源创建和缓存
- **策略模式**：可插拔的渲染和音频后端

## 扩展点

- 自定义命令处理器
- 新资源类型的资源加载器
- 渲染后端
- 音频系统实现

## 构建与部署

- **框架**：.NET 10
- **输出**：独立可执行文件或库
