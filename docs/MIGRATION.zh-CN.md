# 迁移指南

## 从原版 WebGal 迁移到 NGWebGal

### 主要变化

#### 1. 语言与运行时
- **旧版**：JavaScript/TypeScript
- **新版**：C# / .NET 10
- **影响**：更好的性能、类型安全、原生编译

#### 2. 脚本格式
- **旧版**：WebGal Script（基于 JavaScript）
- **新版**：WebGal Script（C# 解释器）
- **兼容性**：大多数脚本兼容；详见下方脚本迁移说明

#### 3. 资源处理
- **旧版**：基于浏览器的资源加载
- **新版**：带缓存的托管资源系统
- **影响**：更快的加载时间、更好的内存管理

### 脚本迁移

#### 变量声明
```csharp
// 旧版 (JavaScript)
var myVar = "value";

// 新版 (兼容 C#)
myVar = "value";  // 仍然支持动态类型
```

#### 对话语法
```
// 语法保持不变
@character "对话文本"
```

#### 命令
大多数命令向后兼容。请查看命令参考以了解已弃用的命令。

### 资源组织

```
project/
├── scripts/          # 游戏脚本
├── images/           # 图像资源
├── audio/            # 音频文件
├── fonts/            # 字体文件
└── data/             # 游戏数据文件
```

### 性能改进

- **启动速度**：由于 .NET JIT 编译，启动速度提升约 50%
- **运行时**：脚本执行速度提升约 3 倍
- **内存**：托管堆提供更好的垃圾回收
- **渲染**：原生图形 API 访问

### 重大变更

1. **插件系统**：旧的 JavaScript 插件需要用 C# 重写
2. **浏览器 API**：无法直接访问浏览器 API；请使用托管等效方法
3. **异步处理**：脚本中改进了 async/await 支持

### 故障排除

- **脚本错误**：查看控制台输出以获取详细错误信息
- **资源加载**：验证资源路径是否相对于项目根目录
- **性能问题**：使用内置性能工具进行分析
